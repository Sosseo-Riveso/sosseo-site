🔌 Conectar Botões do seu Site WordPress ao CRM

Para conectar qualquer clique nos botões de WhatsApp do site sosseo.com.br a este CRM, basta colar o script abaixo no seu WordPress (via plugin de Header/Footer ou WPCode):

<!-- Conector SOSSEO CRM --> <script> document.addEventListener('DOMContentLoaded', function() { // Rastreia cliques nos botões de WhatsApp do site da SOSSEO document.querySelectorAll('a[href*="wa.me"], a[href*="whatsapp.com"]').forEach(function(btn) { btn.addEventListener('click', function() { fetch('https://sosseo-crm.sosseosites.workers.dev/api/leads', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ company: 'Lead do Site SOSSEO', contact: 'Contato via WhatsApp', phone: 'Clique no Botão', source: 'WhatsApp', service: 'Criação de Site / Tráfego', status: 'novo', notes: 'Clique originado na página: ' + window.location.pathname }) }).catch(function(e) { console.log('CRM tracking:', e); }); }); }); }); </script>
